Full Stack Development

Full stack development means building both the front end (user interface) and back end (server, database, APIs) of an application.

Concept of AI

AI (artificial intelligence) is the concept of building machines or software that can perform tasks normally requiring human intelligence, such as learning, reasoning, problem-solving, understanding language, and recognizing images.

Object-Oriented Programming and Design

OOPD (Object-Oriented Programming and Design) is an approach to building software by modeling it as a collection of objects, each combining data (attributes) and behavior (methods). Its core principles are encapsulation, abstraction, inheritance, and polymorphism.

Functional Programming (FP)

A programming paradigm that builds software from pure functions, immutable data, and function composition, avoiding shared state and side effects.

Procedural Programming

A paradigm that organizes code as a sequence of step-by-step procedures (functions) operating on data, as in C or early Pascal.
